The String Matching Problem

The string matching problem, also called pattern matching, is a fundamental probelem in computer science and bioinformatics. It involves finding one or more occurrences of a pattern string P within a text or query string T. We denote the length of a given string s as \(|s|\).

Formally, the goal is to find all positions i in T such that:

\[ T[i..i+m-1] = P \]

The problem underlies many practical applications, such as:

  • Searching for DNA motifs or protein sequences in bioinformatics
  • Text searching in word processors or search engines
  • Plagiarism detection and data mining

Below, I will present a few algorithms to solve the pattern matching problem.

Naive Exact Matching

The simplest, most straighforward solution is to simply align the start of pattern string P to the start of query string T and compare the characters of both strings index-wise. Once a mismatch occurs, we terminate the comparison since we already know that the two strings do not exactly match. After, we shift string P one character to the right and repeat the comparison. We do this until we reach the \(|T| - |P| + 1\) position where the last character of each string aligns. We illustrate this by finding the pattern brown within the text The quick brown fox:

The quick brown fox
brown brown
 brown brown
  brown brown
   brown brown
    brown brown

We find that there is a match between the pattern and the text at the 10th position. We can write a function that implements this comparison.

def naive_exact_match(p: str, t: str) -> list[int]:
    """Finds the starting positions where pattern (p) matches text (t)"""
    occurrences = []
    for i in range(len(t) - len(p) + 1):
        match = True
        for j in range(len(p)):
            if t[i+j] != p[j]:
                match = False
                break
        if match:
            occurrences.append(i)
    return occurrences

Passing in our query and text in the previous example, we get the following result:

p = "brown"
t = "The quick brown fox"
naive_exact_match(p, t)
[10]

Boyer-Moore Algorithm

Similar to the exact matching algorithm, we slide pattern string P across text string T to perform our comparison. However, we compare characters from right to left at each alignment. In each alignment, we follow the bad character rule and the good suffix rule.

Bad Character Rule

Upon mismatch, skip alignments until (a) mismatch becomes a match, or (b) P moves past the mismatched character.

Example

Given text T = GCTTCTGCTACCTTTTGCGCGCGCGCGGAA, find the occurrences where pattern P = CCTTTTGC matches using the bad character rule

Step 1

T: GCTTCTGCTACCTTTTGCGCGCGCGCGGAA
P: CCTTTTGC

Shift to the right until \(C\) has a match. Skip 2 alignments.

Step 2

T: GCTTCTGCTACCTTTTGCGCGCGCGCGGAA
P: CCTTTTGC

Move P until it passes the current alignment. Skip 6 alignments.

Step 3

T: GCTTCTGCTACCTTTTGCGCGCGCGCGGAA
P: CCTTTTGC

All characters have been matched!

Good Suffix Rule

Let t = substring matched by inner loop; skip until (a) there are no mismatches between P and t or (b) P moves past t.

Step 1

T: CGTGCCTACTTACTTACTTACTTACGCGAA
P: CTTACTTAC

Shift P to the right until t has a match. Skip 3 alignments.

Step 2

T: CGTGCCTACTTACTTACTTACTTACGCGAA
P: CTTACTTAC

Move P until its prefix matches t. Skip 3 alignments.

Step 3

T: CGTGCCTACTTACTTACTTACTTACGCGAA
P: CTTACTTAC

All characters have been matched!

In Boyer-Moore matching, both the bad character and good suffix rules return the number of skips we can do in pattern matching. The decision in which rule to use is simply the one that yields a higher number of skips. We then shift our pattern P by our number of skips, then recompute a new skip count from the two rules. We repeat the process until we either find an exact match or reach the end of text T.

A caveat to this approach is that we need to build separate indexes from pattern P for both the bad character and good suffix rules. I won’t go into the detail of the pre-processing step, just think of it as a way to efficiently compute the number of shifts needed after evaluating an alignment. Explore the code is provided below:

Code 
def build_bc_table(pattern: str) -> dict[str, int]:
    """Maps each character to its last index in the pattern"""
    bc = {}
    for i, c in enumerate(pattern):
        bc[c] = i
    return bc

def build_gs_table(pattern: str) -> list[int]:
    """Preprocess the pattern to create good suffix shift table."""
    m = len(pattern)
    gs = [0] * m
    border_pos = [0] * (m + 1)

    # Step 1: Precompute border positions
    i = m
    j = m + 1
    border_pos[i] = j

    while i > 0:
        while j <= m and pattern[i - 1] != pattern[j - 1 if j < m else 0]:
            if gs[j - 1] == 0:
                gs[j - 1] = j - i
            j = border_pos[j]
        i -= 1
        j -= 1
        border_pos[i] = j

    # Step 2: Precompute shifts for prefixes
    j = border_pos[0]
    for i in range(m):
        if gs[i] == 0:
            gs[i] = j
        if i == j:
            j = border_pos[j]

    return gs

We can now combine both rules to implement the Boyer-Moore algorithm.

def boyer_moore_search(text: str, pattern: str):
    """Boyer-Moore search using the Bad Character and Good Suffix heuristics"""
    n = len(text)
    m = len(pattern)
    if m == 0 or n == 0 or m > n:
        return []

    # Precompute indexes
    bc = build_bc_table(pattern)
    gs = build_gs_table(pattern)

    matches = []
    shift = 0

    while shift <= n - m:
        # Start from right-most position of current alignment
        j = m-1

        # Compare from right to left
        while j >= 0 and pattern[j] == text[shift+j]:
            j -= 1

        if j < 0:
            # Match found at index = shift
            matches.append(shift)
            # Shift so that next character after matched substring aligns
            shift += gs[0] if m > 1 else 1
            print(f"MATCH: shifting pattern to start at index {shift-1}")
        else:
            # Compute shifts
            bc_shift = j - bc.get(text[shift+j], -1)
            gs_shift = gs[j] if j < m - 1 else 1


            shift += max(bc_shift, gs_shift)
            if bc_shift > gs_shift:
                print(f"Using Bad Character rule: shifting by {shift} positions")
            else:
                print(f"Using Good Suffix rule: shifting by {shift} positions")

    return matches
